概览

QEMU

本周以 TCG 与 QOM 基础设施重构为主线，tlb_fill 接口、HMP 可选化、设备生命周期规范化均有新版本；Arm64 命名 CPU 模型与可配置 host 模型叠加推进，为迁移能力打基础。

KVM

KVM 处于高密度评审期：guest_memfd 在 direct map 移除、原址转换、脏页记录三条线上并行迭代；TDX/SEV-SNP/Arm CCA 机密计算特性均有新进展，时钟与 TSC 清理也同步进行。

Libvirt

Libvirt 功能补全与缺陷修复并重：TLS-PSK 迁移、nwfilter nftables 后端、iothread poll-weight 等候选特性仍在评审，remote 流死锁与 CD-ROM detach 等缺陷修复获得认可。

guest_memfd 页管理语义

本期变化：T003 的 direct map 移除 v12 获得多方 Reviewed-by；T005 的 in-place conversion v10 讨论属性命名；T013 新提出 gmem-only memslot 的 dirty logging RFC，三者共同塑造 guest_memfd 的页管理语义。

讨论中：direct map 在 TDX/SEV-SNP 下的排除条件、转换 API 命名及 gmem-only slot 的动态 flags 切换仍待收敛。

KVM 时钟与 TSC 可信化

本期变化：T018 v7 将 pvclock_vcpu_time_info 移入 UAPI 并为时钟修正预留新接口；T023 v6 以 SNP/TDX 安全时钟为目标重构 PV clock 与 TSC 关系。

讨论中：masterclock 重采样是否必要、TSC 频率可靠性校验与 PV clock 去重逻辑尚未定论。
