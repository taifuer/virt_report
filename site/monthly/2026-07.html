概览

QEMU

本月 QEMU 侧重构建与调试基础设施现代化：tests/tcg 向 meson 迁移推进到 v6，accel/tcg 用 IntervalTree 重构断点；ARM 侧合入 FEAT_FP8/MTE4，同时 RME Realm、可定制 host model 等 RFC 继续演进。安全与正确性修复（omap_dma、trap、Hygon）同步接受评审。

KVM

CoCo 仍是 KVM 主线：guest_memfd 原地转换 v8、TDX DPAMT v7、SEV VMSA 释放修复与 Secure AVIC/RMPOPT 并行推进；Arm CCA v14 及 FEAT_NV/GICv5 继续迭代，另有 KVM clock 清理接近合入。

Libvirt

Libvirt 围绕 QEMU 11.1 能力同步展开：monitor QMP/HMP QOM 化进入 v7，迁移 TLS-PSK、iothread poll-weight、crash dump 格式选择等运维特性活跃；ARM CPU 多值属性与 vCPU 热插顺序仍处 RFC 阶段。
