别名窗口与地址查找

切换设备窗口和映射偏移，再选择地址，观察区域图怎样展开为可见区间。

输入 0x 开头的十六进制或十进制地址，范围 0—0xfffc，需 4 字节对齐。

当前区域关系


    
system 可见布局

    

    
每格 4 KiB，点击查看格内偏移 4 的位置。RAM、A、B 分别表示 ram、regs-a、regs-b；空表示未映射。

    
当前 FlatRange（不包含未映射区）
system 范围目标区域起始偏移

    

    
    
  
    
  
    默认配置下，0x2004 经 window 映射到 bus 的 0x1004，命中 regs-a 的偏移 4。0x3004 对应 bus 空洞，回落到 ram 的偏移 0x3004。关闭窗口后，这两个地址都由 ram 处理。启用 JavaScript 后可切换布局和查询地址。
    
  
    这是固定布局的地址计算模型，不执行真实设备读写。可见区间按本例 4 KiB 边界计算；完整 QEMU 实现还支持更细的区域、访问拆分、权限和 IOMMU 转换。关闭窗口不会清除被遮盖的 RAM。
