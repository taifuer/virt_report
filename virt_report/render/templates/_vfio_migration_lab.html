等待初始加载确认

预拷贝场景启用了初始数据加载确认。页数用于对照两条传输路径；实际迁移中，最终 RAM 和设备数据可以交错到达。

  1. 源端继续运行，QEMU 迭代客户机 RAM；设备预拷贝同时传输显存 F、G。
  2. GPU 最后一次更新 F，并通过 DMA 把完成记录写到 RAM 页 C。
  3. VF 停止后，C 通过 RAM 迁移重传；F 和动态硬件状态通过 VFIO 数据 FD 传输。仅停机拷贝的对照此时还要传 G。
  4. 目的端导入完整状态，接管计算。若在预拷贝期间取消，源端继续运行。
