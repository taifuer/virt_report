L1 场景采用直接处理通知的简化 Hypervisor；ioeventfd 场景已注册匹配本次端口、长度和值的 PIO 通知。只演示一条成功完成的指令，不包含初始化时的 VMX 指令、并发中断和进入失败。

  1. L1 执行 VMLAUNCH，L0 检查 VMCS12 并构造 VMCS02，进入 L2。
  2. L2 执行 OUT，物理 CPU 退出到 L0。
  3. L1 拦截时，L0 保存退出记录并恢复 L1；L1 处理后更新 RIP，再以 VMRESUME 进入 L2。
  4. L1 放行时，L0 经匹配 ioeventfd 或外层 QEMU 完成访问，继续 L2；不会给 L1 合成这次 I/O 退出。
