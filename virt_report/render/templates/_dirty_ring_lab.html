    1. vCPU 0 写 P3，KVM 向它的环中发布 slot = 0, offset = 3, DIRTY。
    2. QEMU 收割该记录，设置 KVMSlot 位图中的 P3，并将环条目标记为 RESET。
    3. KVM_RESET_DIRTY_RINGS 完成重新保护，条目可回收。
    4. QEMU 合并迁移待发送位图，随后读取并传送 P3。
    5. 重新保护后的再次写入会产生新记录，后续同步仍能发现该页。
