    源端 QEMU页面批次 → 多条有序数据通道 → 页面装载目的端 QEMU
    1. 源端为各通道分派同一 RAMBlock 的页面批次。
    2. 各发送线程处理完任务后，在本通道写入 SYNC；主线程等本地线程完成后写出主流 FLUSH。
    3. 目的端数据通道依次装载页面，收到 SYNC 后等待。
    4. 目的端主流收到 FLUSH，并收齐全部通道的 SYNC，随后释放接收线程。

    启用 JavaScript 后，可逐步观察页面版本、通道延迟和两端的同步状态。

    每步为逻辑时刻，不代表毫秒或带宽；每批用两页代表实际批次。延迟施加在通道 1 的接收端，通道内仍严格有序。示例只推进两组 RAM 传输，不包含 CPU / 设备状态保存与客户机启动；切换参数会重置过程。
